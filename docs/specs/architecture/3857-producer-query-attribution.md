## Intended behaviour and scope

It must not certify partial state, advance its completed checkpoint, retire an unrelated owner or damage a fresh correlated query. A complete provider result that already includes the live version is still not a selected reply. The consumer must resume from its last completed checkpoint inside its existing overall deadline. Post return and push flushing do not certify hosted handling.

No Core production defect is demonstrated. The replacement will make the known Core boundary directly auditable with a bounded Linux gated proof.
