## Intended behaviour and scope

A complete query cancelled by uncovered live publication before selection must return its own content-free retryable refusal. It must not certify partial state, advance its completed checkpoint, retire an unrelated owner or damage a fresh correlated query. A complete provider result that already includes the live version is still not a selected reply. The consumer must resume from its last completed checkpoint inside its existing overall deadline. Post return and push flushing do not certify hosted handling.

No Core production defect is demonstrated. The replacement will make the known Core boundary directly auditable with a bounded Linux gated proof. Native observations remain separate and must not be overstated as an exclusive historical failure path. The separate Mobile repair and its acceptance remain with Mobile 2494.

## Security review

Verdict: PASS for this planned test/evidence replacement. This is an author design review, not independent approval of an implementation.

- Logging/export boundary: the historical local patch logs connection metadata into a private controlled harness only. It is retained as inert evidence and is not applied to shipping source. The replacement test emits fixed synthetic aliases, numeric query/checkpoint facts and public error codes. It must never serialize real connection/conversation IDs, pointers, message bodies, paths containing secrets, keys or credentials. Optional evidence uses exclusively created private files.
- Ownership and isolation: capture and compare actual query/inbox pointers under the existing hosted mutex. Refusal must bind the captured query and inbox; prove that the current inbox remains live and that a fresh query from the unchanged checkpoint succeeds. Existing newer-version, foreign-epoch, owner, unavailable and generation guards remain mandatory. No production authority check is relaxed.
- Evidence integrity: freeze metadata before export, retain exact hashes and distinguish observed facts from source-derived inferences. A missing native generation token or terminal packet cannot become a directly observed event by prose. The new controlled proof supplies those boundaries explicitly and does not retroactively authenticate the old run.
- Cleanup: reuse the fixture's cancellation/join cleanup. Add no unowned worker or sleep/retry. An optional trace must close its file explicitly and surface write/close errors. Failure cleanup must still cancel the held provider and join owned work.
- Runtime surface: no new production behaviour, dependency, protocol field, deadline, pin, deployed binary or authentication route. Raw native logs and APKs remain private on the Mac. Mobile acceptance remains separate.
