# Ticket #856 — `internal/contextwindow.Read`: context-window usage reader over the resolved transcript

Leaf of #855, sibling split to #857 (wire child, blocked on this). Mirrors the
#847→#848 settings-on-snapshot split: this ticket ships the primitive
**unwired**, #857 consumes it onto `screen_snapshot`. Not `security-sensitive`
— read-only reflection of non-secret runtime state from an already-trusted,
already-confined local transcript path.

## Implementation

One production file, ~90 LOC: `internal/contextwindow/usage.go`. New standalone
package (no dependency on `internal/sessions`, so it doesn't belong inside
that package and doesn't force `internal/sessions` to gain its first import of
`internal/agentrun/jsonl`).

Two exported symbols: `Usage{UsedTokens, WindowTokens int}` and
`Read(path string) (Usage, error)`. `Read` opens the transcript, loops
`jsonl.Reader.Next()` to `io.EOF`, and tracks the **last** `Event.Usage != nil`
seen — last-usage-wins. `UsedTokens` sums that entry's four fields
(`InputTokens + CacheReadInputTokens + CacheCreationInputTokens +
OutputTokens`); `WindowTokens` is always `defaultWindowTokens = 200_000`
(single documented default, no per-model map — every current Claude model
shares the 200K window, so building one now would be a defense for a
divergence that hasn't shipped).

Three-way error split: `path == ""` and "scanned, no usage entry" both return
`Usage{0, 200_000}, nil` (deterministic zero, not an error); `os.Open` failure
or a non-`io.EOF` scan error returns a wrapped error with a zero `Usage`. This
keeps "fresh session" distinguishable from "couldn't read".

Full design, algorithm rationale, and the "why reuse `jsonl`" argument:
[features/contextwindow-package.md](../features/contextwindow-package.md).

## Testing

`internal/contextwindow/usage_test.go` (table-driven, `t.Parallel()`, stdlib
only) + hand-written `testdata/*.jsonl` fixtures copied from
`internal/agentrun/jsonl/testdata/clean.jsonl` with edited `usage` numbers:

- `latest_turn.jsonl` — AC-1: two usage-bearing entries plus a trailing
  usage-less assistant line (transitional thinking-block); asserts the sum
  comes from the *last* usage entry (`7500`) and the trailing no-usage line
  doesn't clear it.
- `compaction_reset.jsonl` — AC-3: an earlier turn summing to `150000` and a
  later, smaller turn summing to `30000` (the post-auto-compaction shape);
  asserts `Read` reports the smaller, later figure.
- `no_usage.jsonl` — AC-4: only `user`/`system` lines, no assistant/usage
  entry; asserts `Usage{0, 200_000}, nil`.
- `TestRead_EmptyPath` — AC-4: `Read("")` returns `Usage{0, 200_000}, nil`
  without opening anything.
- `TestRead_OpenError` — a non-existent non-empty path returns a wrapped
  error (`errors.Is(err, fs.ErrNotExist)`) and a zero `Usage`.
- AC-2 (window always reported) is folded into every table case: each
  asserts `WindowTokens == defaultWindowTokens`.
- AC-5 (unwired) is structural — fresh package, zero non-test importers; no
  dedicated test.

## Lessons learned

- Real on-disk claude transcript lines nest `usage`/`model` under a top-level
  `message` object with a top-level `type` field — hand-written fixtures must
  match that outer shape (not a bare `{"usage": {...}}`) for `jsonl.NewReader`
  to classify the line as an assistant entry and populate `Event.Usage`. The
  spec's guidance to "copy a couple of `clean.jsonl`'s lines and edit the
  numbers" is the reliable way to get the shape right; hand-rolling the
  envelope from the field list alone risks silently producing a line the
  reader skips as non-assistant.

## Out of scope

- Wiring `Read` into `screen_snapshot` or any consumer — sibling #857.
- Per-model context-window sizing (`message.model` → window map). Not built:
  no non-200K Claude model exists yet (evidence-based). The model is already
  available on `jsonl.Event.Raw` if this becomes needed — a localised
  `windowForModel(string) int` helper, not a `Read` rewrite.
- Bounded/tail scanning using the resolver's reported transcript size.
  Deferred — transcripts are tens-to-low-hundreds of KB and this is an
  on-demand snapshot read, not a hot loop; revisit only if profiling shows it
  matters.
