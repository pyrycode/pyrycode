# Ticket #1148 — `internal/transcript`: probe-preferred resolver core + shared UUID-stem constant

Split from #973. Foundation slice: ships a new leaf package with full internal test coverage and **wires no consumer**. `internal/sessions/reconcile.go` (Family A), `cmd/pyry/interactive_turn_stream_v2.go` (Family B), and `internal/sessions/rotation/watcher.go` are untouched — they migrate onto the new package in sibling tickets blocked by this one.

## Implementation

Two files, `internal/transcript/transcript.go` (225 lines) + `transcript_test.go` (427 lines), PR #1155.

- `Ext` (`.jsonl`) and `ValidStem` — the single source of truth replacing the three byte-identical `uuidStemPattern` regexps in `reconcile.go`, `interactive_turn_stream_v2.go`, and `rotation/watcher.go`.
- `Probe` — a one-method interface (`OpenJSONL(pid int) (string, error)`) **redeclared locally**, not imported from `internal/sessions/rotation`, so the package stays a leaf; `rotation`'s existing `*Probe` values satisfy it structurally.
- `CanonicalDir`, `GuardProbedPath` — the confidentiality guard extracted into one standalone, independently-tested function, closing the untrusted→trusted crossing at `probe.OpenJSONL`.
- `Result{Path, Size}` + `Found()` — the neutral carrier (AC4). No not-found convention, no cold/warm offset rule baked in; those stay in the adapters.
- `StatByID`, `Newest`, `Probed` — by-id/pinned stat, newest-by-mtime scan, and probe-preferred resolution, each a pure function over its arguments plus read-only `os` calls (no goroutines, no locks).

Full design write-up: [features/transcript-package.md](../features/transcript-package.md).

## Patterns established

- **Composable primitives over a mega-resolver when two callers diverge on more than one axis.** Family A and B diverge on not-found convention, offset semantics, *and* pinned-vs-probe dispatch order — no single resolver closure could serve both without changing one family's behaviour. The fix is independent building blocks (`StatByID`/`Newest`/`Probed`) the adapters compose in their own order, not a parameterized mega-function.
- **Redeclare a minimal interface locally to break an import cycle, rather than importing the concrete type.** `transcript.Probe` is a structural copy of `rotation.Probe`'s one method, not an import — this is what lets `sessions`, `rotation`, and `cmd/pyry` all import `internal/transcript` later with no back-edge.
- **A neutral result type outlives its first two callers.** `Result{Path, Size}` deliberately omits the not-found convention (nil-empty vs. wrapped error) and the offset rule (always-size vs. cold/warm) — both are call-site decisions, not properties of "did resolution succeed."

## Lessons learned

(From the PR #1155 body.)

- The core stays a leaf by redeclaring the one-method `Probe` interface locally (rotation's `*Probe` satisfies it structurally) — this is what lets `sessions`, `rotation`, and `cmd/pyry` all import it later without a cycle.
- `GuardProbedPath` is now a standalone, independently-tested confidentiality boundary that returns `("", false)` on reject (no rejected-path string in any returned error) — a security-conscious adapter that wants rejection observability calls it directly and logs on `!ok`.

From code review (PR #1155, PASS, non-gating NITs the sibling migrations must account for):

- `Newest` captures `Size` during the mtime scan rather than re-statting the winner. This is an improvement (one fewer syscall, no double-stat TOCTOU) but changes an observable: a file vanishing between scan and use now yields the scan-time size instead of a surfaced `os.Stat` error. Family A's migration should expect this diff.
- `StatByID` returns an error on an invalid stem, where Family A's current inline pinned-id path instead falls through to the probe. The Family A adapter must preserve that fall-through explicitly rather than naively mapping "`StatByID` error → nil-empty."

## Out of scope (named in the ticket, unchanged)

- Wiring any consumer — Family A, Family B, and the rotation watcher stay byte-identical, including their three duplicate regexps.
- Deleting `mostRecentJSONL`, `newProbePreferredTranscriptResolver`, the `resolve*JSONL` family — removed only when their consumers migrate, per sibling ticket.
- The `availabilityReporter`/`probeUsable` no-lsof dispatch helper both families carry locally — not one of the core's four owned mechanics (open question 3 in the spec).
