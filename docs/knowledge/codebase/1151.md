# Ticket #1151 — rotation watcher's UUID-stem regexp migrated onto `internal/transcript`

Split from #973. The last of the three triplicated UUID-stem regexps: `internal/sessions/rotation/watcher.go`'s local `uuidStemPattern` is retired in favour of `transcript.ValidStem` (#1148), completing the single-source-of-truth migration alongside Family B (#1150). Pure mechanical swap, no behaviour change.

## Implementation

PR #1159, one file (`internal/sessions/rotation/watcher.go`), net -6 lines (3 edits).

- Deleted the `uuidStemPattern` var and its two-line comment.
- Deleted the now-unused `regexp` import; added `github.com/pyrycode/pyrycode/internal/transcript` in the existing internal-import group (after `fsnotify`, per `goimports`).
- Swapped the call site in `handleCreate`: `uuidStemPattern.MatchString(stem)` → `transcript.ValidStem(stem)`. `stem` was already bare (`.jsonl` stripped one line earlier via `strings.HasSuffix`), so the swap needed no argument reshaping.

**Scope boundary held:** unlike the sibling migrations (#1149/#1150), this file sheds only `regexp` — the `strings` import and its `.jsonl`-suffix check at the top of `handleCreate` stay untouched. `ValidStem` wraps the identical regexp, so the swap is byte-identical behaviour; no new tests were needed.

## Patterns established

- **Not every migrating call site sheds the same imports.** The sibling `internal/transcript` adapters (#1149/#1150) each dropped both `regexp` and `strings`; this one drops only `regexp` because its `.jsonl`-suffix check (a `strings.HasSuffix`, unrelated to the UUID-stem matcher) lives in the same function. Match the migration to what the call site actually uses, not to what the last sibling ticket did.

## Out of scope (named in the ticket, unchanged)

- Family A (`internal/sessions/reconcile.go`, #1149) and Family B (`cmd/pyry/interactive_turn_stream_v2.go`, #1150) — separate tickets, migrated independently.
- Any change to `handleCreate`'s control flow, signatures, or the probe-retry schedule — only the single matcher expression changed.

## Testing

`go test -race ./internal/sessions/rotation/...`, `go vet ./...`, `go build ./cmd/pyry`, `gofmt` all green. No new tests — `ValidStem` is byte-identical to the deleted regexp, so `TestWatcher_SkipsMalformedUUID` (the matcher-branch invariant) and `TestWatcher_SkipsNonJSONL` (pins the retained `strings`/`.jsonl` branch) pass unedited.
