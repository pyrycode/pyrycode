# Ticket #1088 — `internal/streamsup`: turn envelope write + stdout stream-json → turnevent parser

Second slice of `internal/streamsup`, built on the [#1087](1087.md) process-lifecycle slice. Fills the
two seams #1087 left unwired — `Runner.Stdin() io.Writer` and `Config.Stdout io.Writer` — with the
**turn I/O boundary**: the send half (`WriteTurn`, a user-turn stream-json envelope onto the held-open
stdin, never closing it) and the receive half (`Parser`, each stdout stream-json line → a neutral
`turnevent.Event`). Two additive production files; `runner.go` and `internal/supervisor` are untouched.

Full design writeup: [features/streamsup-package.md](../features/streamsup-package.md).

## Implementation

- `envelope.go`: `WriteTurn(w io.Writer, prompt []byte) error` + unexported `marshalTurnEnvelope`.
  Mirrors `streamrunner`'s `userTurn`/`userTurnMessage`/`userTurnContentText` envelope shape verbatim
  (`{"type":"user","message":{"role":"user","content":[{"type":"text","text":"…"}]}}`). The prompt is
  carried as a JSON string value and `json.Marshal`-escaped, so the marshalled envelope is always a
  single physical line; `WriteTurn` appends the one trailing `'\n'` and never closes `w`. `w == nil` →
  `ErrNoLiveChild` (the exact shape `Runner.Stdin()` returns between spawns).
- `parser.go`: `Parser` (an `io.Writer` set as `Config.Stdout`), `NewParser(sink func(turnevent.Event),
  logger *slog.Logger)`. Accumulates bytes, splits on `'\n'`, drops an oversized unterminated partial
  past `maxBuf` (4 MiB, streamrunner's value). Decodes each line into a minimal local shape and
  switches on the line's **top-level `type` only** (nested content is never re-scanned for control
  types): `assistant` → one event per content block (`text`→`TextChunk`, `thinking`→`ThoughtChunk`,
  `tool_use`→`ToolStart`); `user`/`tool_result` blocks → `ToolUpdate`; `result` → the turn boundary,
  exactly one `TurnEnd{Reason: TurnEndReasonEndTurn}`; `system` (`init`/`thinking_tokens`/`status`),
  `rate_limit_event`, unknown types, and malformed lines → dropped, Debug-logged by type/reason only
  (never content).
- **Turn-stateless parser.** No turn counter, no `awaiting` flag, no per-session accumulator — only
  the partial-line byte buffer. The only turn boundary is a `result` line, which is what makes zero
  cross-turn bleed (AC3) structural rather than tracked.
- **No mutex.** `os/exec` drives a non-`*os.File` `Config.Stdout` through exactly one internal
  `io.Copy` goroutine, so `Parser.Write` is only ever invoked serially from that one goroutine — unlike
  streamrunner's `streamParser`, which locks because a separate watchdog goroutine reads its state.
  This slice adds no goroutines of its own.
- `tool_use` input is carried through as claude's already-decoded `json.RawMessage` bytes verbatim
  (empty → nil) rather than mirroring `mapper.go`'s map-re-marshal approach — one fewer parse, and it
  preserves the original key order for what is an opaque pass-through field (`ToolStart.RawInput`).
- `helper_test.go` (#1087's `TestMain`-dispatch fake-child harness) grows a `stream_json` mode: reads
  newline-delimited user-turn envelopes from stdin, and per envelope emits a canned
  `system/init` → `assistant text (echoing the decoded prompt)` → `result/success` triple with a
  constant `session_id` across turns (per the T1 spike: id is constant, only init repeats per turn).

## Patterns established

- **Two additive seams over a shared runner, zero runner diff.** Following [#1077](1077.md)'s
  interface-seam precedent, a slice that fills a producer's pre-declared extension points doesn't need
  to touch the producer at all — `WriteTurn` is a free function taking `Runner.Stdin()`'s return value,
  and `Parser` is just the `io.Writer` the caller assigns to `Config.Stdout`. No new wiring type, no
  `runner.go` edit. Future streamsup slices (#1089) should look for the same seam-filling shape before
  reaching for a new coupling point.
- **Mirror-not-import for unexported cross-package helpers.** `mapper.go`'s `toolKind`/`toolStatus`/
  `toolResultContent`/`rawInput` are unexported and keyed on `tuidriver.JSONLEntry`, so they're
  re-implemented here on the parser's own already-decoded fields rather than imported — deliberate,
  ticket-sanctioned duplication that avoids recoupling the clean stream-json package to the PTY
  substrate (`tui-driver`). Don't refactor this into a shared package; the spec calls this out
  explicitly.
- **Segment on top-level `type` only, never nested content.** The security property (a tool result
  whose text is literally `{"type":"result"}` cannot forge a turn boundary) falls directly out of this
  rule: only the outer JSON object's `type` field is ever inspected for control purposes.

## Lessons learned

- **`substrate-guard` bans claude-TUI substrate literals outside its allowlist — including in test
  fixtures.** The injection-resistance test's "unicode and control bytes" case originally embedded a
  literal ESC-CSI sequence (`\x1b[31m`) to exercise "control bytes survive `json.Marshal` escaping."
  `cmd/substrate-guard` flagged it as a banned claude-TUI substrate literal (those belong in
  `tui-driver`, not here). Fixed in 803e878 by swapping to generic C0 control bytes (NUL/BEL/BS/US),
  which exercise the identical security property without the substrate literal. When a test fixture
  needs "some control bytes," prefer generic C0 bytes over anything that looks like a real terminal
  escape sequence — `substrate-guard` runs repo-wide, not just on production code.
- **(From the PR body.)** gofmt 1.26 reflows this repo's aligned doc-comment continuations (e.g.
  `helper_test.go`'s mode list). CI gates on vet+test+staticcheck, not gofmt, and the committed
  convention keeps the aligned style — running `gofmt -w` on such a file churns a sibling's committed
  comment into the diff. Restore the aligned form and match it for new entries to keep an additive
  slice's diff actually additive.
- Code review flagged (NIT, not a blocker for this unwired slice): `Parser.buf` is not reset across a
  child crash-restart, since the same `Parser` instance is reused as `Config.Stdout` on every respawn.
  A crash mid-line leaves a stale partial that concatenates with the restarted child's first bytes,
  forms one garbage line that fails to decode, and is dropped — parsing self-heals at the next `\n`; at
  most one lost line. **#1089 (which owns turn-level restart recovery) should reset the parser's line
  buffer on restart if cross-crash turn integrity matters there.**
- Code review also noted a minor mapping divergence from `mapper.go`: an empty assistant `text` block
  here emits `TextChunk{Text: ""}`, where `mapper.go` drops empty text. Judged defensible (the parser
  keys on the explicit block `type`, so an empty text block genuinely is a degenerate text event) and
  harmless downstream — left as-is, noted only because the spec says "mirror `mapper.go`."
