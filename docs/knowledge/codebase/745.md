# Ticket #745 — ADR 027: internal turn-event ↔ ACP mapping

Doc-only ticket. Ported the canonical **internal-turn-event → ACP mapping**, the
six divergences, and the ACP taxonomy reference out of the personal design vault
into an in-repo ADR — [`decisions/027-acp-mapping.md`](../decisions/027-acp-mapping.md),
sibling to [ADR 025](../decisions/025-mobile-remote-head-interactive-session.md).
No code shipped. The mapping is now versioned next to the code that implements
it, so every child of epic [#600](https://github.com/pyrycode/pyrycode/issues/600)
(`pyry acp`, decomposing into T2–T10) builds to **one authoritative contract**
instead of re-deriving it from vault prose the headless developer run cannot open.

Sub-issue of #600. Not security-sensitive — no implementation surface, no trust
boundary, no wire/crypto change. Spec:
[`specs/architecture/745-acp-mapping-adr.md`](../../specs/architecture/745-acp-mapping-adr.md).

## Patterns established

- **A vault→repo port is a code-grounding exercise, not a transcription.** Every
  named type is verified against live code, and any concept the vault lists but
  the repo has not built is flagged (built / planned-deferred / other-surface) so
  the contract stays honest about what an implementer will actually find in
  `internal/turnevent` today. This built-vs-planned discipline is the ADR's whole
  value over the vault prose.
- **Divergence numbering is a cross-ADR contract.** ADR 026 references
  "divergence 6" before the numbered list exists in-repo; ADR 027 must define the
  canonical 1–6 so the earlier ADR resolves. When an ADR cites another by number,
  the cited list becomes load-bearing and cannot be renumbered freely.
- **Code-review NIT applied for extra honesty:** the tool-content-shapes row now
  flags ACP `image` / `resource` blocks as *planned* — only `text` → `TextContent`
  is built in `content.go` (which builds only text/diff/terminal). Collapsing all
  three ACP block kinds to `TextContent` would have contradicted the ADR's own
  built-vs-planned discipline.

## Lessons learned

- **The real-claude e2e spike golden file churns into unrelated PRs.**
  `internal/e2e/realclaude/testdata/permission_protocol_v2.1.158.json` was swept
  into this doc-only branch (52 lines of pure per-run non-determinism: session
  UUIDs, temp-dir suffixes, thinking text/signatures, token counts) by the
  dispatcher's "auto-commit uncommitted changes" backstop — **not the developer's
  work** (the developer's only commit adds the ADR). Root cause is structural:
  `TestRealClaude_PermissionProtocol_Spike` atomically rewrites
  `testdata/permission_protocol_v<version>.json` on *every* e2e run, the path is
  not gitignored, and any agent that runs `make check` / the e2e suite re-dirties
  it — so it recurs by design (the same churn rode in on #756/#757/#761/#762/#747
  and is already on `main`). **Zero test-correctness impact:** the regression
  consumer globs `permission_protocol_v*_*.json` (requires a `_<mode>` token),
  which this raw spike output lacks, so it is never asserted against. Reverted to
  main's blob here to keep the doc-only PR clean. **Operator follow-up:** gitignore
  the raw spike output (or exclude non-`_<mode>` `testdata/permission_protocol_v*.json`
  from the safety-net commit) so doc PRs stop carrying it.
- **A doc body's ADR number is stale the moment a sibling lands.** #745's body and
  AC both said `026-acp-mapping.md`, hedged with "confirmed free at refinement."
  Under a decomposing epic, siblings land ADRs in the gap between refinement and
  authoring (here #761 took 026). Always `ls docs/knowledge/decisions/` at author
  time and grep whether a landed sibling already cites your artifact by number
  (026 cites "divergence 6" → 027 is that list's home) before committing to a
  number.

## Out of scope (by design)

- **No code.** The mapping is a design contract T2–T10 build to; this ticket only
  records it. The neutral events flagged *planned* (`BusyState`, inbound `Prompt`,
  `DropQueued`) are built by later epic tickets, not here.
- **`ThoughtChunk`-robustness verification** (whether claude reliably streams
  thinking into the JSONL log, or the mapping degrades to screen-scraped
  `BusyState`) is scoped to the Phase-2 bridge epic #596 — recorded as open item
  3, not resolved here.
