# Ticket #1077 — `sessions.Runner` seam + `RunnerFactory`

Interface-introduction slice of a Strangler Fig for the Streamrunner Interactive work: extracts a narrow `sessions.Runner` interface (already satisfied by `*supervisor.Supervisor`) plus a `RunnerFactory` injection seam on `Config`, so T4/T7 can swap in an alternative runner behind the same session lifecycle. No behaviour change — when `RunnerFactory == nil` the factory defaults to `supervisor.New`, keeping today's PTY / interactive path byte-identical. That nil default is the rollback guarantee.

Full design writeup: [features/sessions-package.md § `Runner` interface + `RunnerFactory`](../features/sessions-package.md).

## Implementation

- New file `internal/sessions/runner.go`: the 5-method `Runner` interface (`State`, `WriteUserTurn`, `WaitForPTY`, `Run`, `Restart`), the compile-time assertion `var _ Runner = (*supervisor.Supervisor)(nil)`, and the `RunnerFactory func(supervisor.Config) (Runner, error)` type.
- `Session.sup` (`session.go:133`) re-typed `*supervisor.Supervisor` → `Runner`.
- `Config.RunnerFactory` (`pool.go`) is normalized once in `Pool.New` into a never-nil `newRunner`, stored on `*Pool` (mirrors the `log` field: set once, read-only, no lock). Both construction sites route through it: the bootstrap in `New` (`bootstrapSup` local re-typed `Runner`) and `Pool.buildSession` (`p.newRunner`), the shared funnel for `Create`/`CreateIn`/`GetOrCreate`/`GetOrCreateIn`.
- `Session.Supervisor()` keeps its concrete `*supervisor.Supervisor` return type — the accessor's body becomes a type assertion (`sup, _ := s.sup.(*supervisor.Supervisor)`) that is total under the nil-factory default. Returns `nil` only once an alternative `Runner` is injected (T4/T7), a state no production caller reaches this ticket.
- New test `internal/sessions/runner_test.go`: a no-op `fakeRunner` + a counting `RunnerFactory`, driving `Pool.New` (bootstrap site) and `p.buildSession` directly (create site, no lifecycle goroutine needed) — asserts the factory ran exactly twice, proving the seam is threaded at both sites rather than merely declared. A bogus `ClaudeBin` guards against the fallback silently succeeding via a real `supervisor.New`.

## Patterns established

- **Interface-introduction slice = only the stored field becomes the interface, not the read accessor.** `Session.sup` (the field) is retyped to `Runner`; `Supervisor()` (the accessor consumers read through) keeps its concrete return. This kept the interface at 5 methods instead of the AC's 12-method discretion menu, and kept all 7 external `Supervisor()` call sites (5 production in `cmd/pyry`, 2 test) plus the `relayWiring.sup` → `interactive_*_v2` → `CurrentConversation()` subtree compiling unchanged — re-typing the accessor would have dragged that whole subtree into this ticket, which is exactly the T4/T7 migration this slice explicitly defers. Apply this pattern to any future consumer-defined-interface extraction where a struct field is being generalized but its accessors have external callers: retype only what a consumer dispatches through the field itself.
- **Compile-time assertion (`var _ Runner = (*supervisor.Supervisor)(nil)`) is the deterministic proof for "interface covers only what compiles."** A sixth speculative method fails only as "unused," but a missing method fails the build — so code review can verify AC completeness mechanically rather than by judgment call.
- **`RunnerFactory` normalize-once-in-`New`, thread-as-a-`Pool`-field pattern** — same shape as `p.log`: resolved once at construction (nil → default wrapper over `supervisor.New`), stored read-only on `*Pool`, no synchronization needed since it's never mutated post-construction. Reusable shape for any future injection seam on `Config`.
