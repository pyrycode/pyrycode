# #1120 — streamsup: interrupt send primitive + `error_during_execution` → cancelled turn end

**Size:** S. Purely additive: 3 production files touched (`envelope.go`, `parser.go`, `runner.go`), 0 new
files, ~2 new exported symbols (`WriteInterrupt`, `Runner.Interrupt`), no consumer cascade. Not
security-sensitive — the interrupt *routing* sibling (#1121, blocked-by this ticket) carries the security
review; this ticket delivers only the streamsup-internal primitive #1121 consumes.

## What shipped

Two independent, additive facets inside `internal/streamsup`, both entirely internal to the package —
neither touches `Run`, the supervise loop, `New`, or the `cmd/pyry` `sessions.Runner` adapter.

**Send half.** `WriteInterrupt(w io.Writer, requestID string) error` (`envelope.go`) marshals and writes
one structured `control_request` line — `{"type":"control_request","request_id":"<id>","request":{"subtype":"interrupt"}}\n`
— onto a child's held-open stdin. It mirrors `WriteTurn` minus the turncommit gate (an interrupt isn't a
queued turn): `w == nil` is checked first and returns `ErrNoLiveChild` with zero bytes written (never a
panic, never a partial write); a write failure (e.g. `EPIPE` mid-teardown) is wrapped, never panics.
`Runner.Interrupt() error` is the one-line method wrap — `WriteInterrupt(r.Stdin(), r.nextInterruptID())`
— backed by a new `interruptSeq atomic.Uint64` field on `Runner` (zero-value-ready, no `New()` change) and
`nextInterruptID()` (`strconv.FormatUint(r.interruptSeq.Add(1), 10)`, monotonic from `"1"`). The id is
locally minted, never caller-supplied, and write-only in this slice — nothing here reads the
`control_response` ack, so a per-runner atomic counter is sufficient (no `crypto/rand`/UUID needed).
`Interrupt` is a concrete `*Runner` method, deliberately **not** added to `sessions.Runner` (kept
un-widened per #1077) — mirrors how `*supervisor.Supervisor` encapsulates `SendEsc` (#726) off the
interface.

**Receive half.** `parser.go`'s `streamLine` decode shape gained a `Subtype string` field (inert for every
line type that doesn't set it). `consumeLine`'s `case "result"` now computes its `TurnEnd` reason via a
new pure helper, `resultTurnEndReason(subtype string) turnevent.TurnEndReason`: `"error_during_execution"`
→ `turnevent.TurnEndReasonCancelled` (claude's interrupt-terminated turn, spike T1 #1075), every other
subtype (including empty/unknown) → `turnevent.TurnEndReasonEndTurn`, unchanged from today. The switch
still keys on the line's top-level `type` only — reading `subtype` happens only inside the already-matched
`result` case, so a tool result whose text literally contains `error_during_execution` still can't forge a
turn boundary.

`turnevent.TurnEndReasonCancelled` already existed (`taxonomy.go:42`) and was already carried through both
downstream wire mappings unmodified — `turnbridge/outbound.go:91` and `cmd/pyry/acp_turn_stream.go:73`
both do a bare `string(e.Reason)` and both already had tests pinning the `cancelled` value — so this
change cascades to **zero** downstream code edits. No new `turnevent` reason was introduced.

## Patterns established

- **Free-function marshal+write, thin method wrap** — `WriteInterrupt`/`Interrupt` reproduces the
  `WriteTurn`/`WriteUserTurn` split so the marshal + nil-refusal + wrap logic is unit-testable against a
  `bytes.Buffer`/nil writer independent of a live `Runner`. Reach for this split again for any future
  streamsup control-line primitive.
- **Structured encoding even with no free-text field** — `controlRequest`/`controlRequestInner` are
  marshalled via `json.Marshal`, never string-concatenated, even though the interrupt line's only
  variable field (`request_id`) is a locally-minted opaque string with no injection surface. Kept for
  symmetry with `marshalTurnEnvelope`'s injection-resistance invariant and to keep the door open for a
  future control subtype that *does* carry free text.
- **`atomic.Uint64` for a cross-goroutine correlation counter, no `New()` touch** — a zero-value-ready
  field added straight to the `Runner` struct; `Interrupt` may be called from a different goroutine than
  `Run`, so `atomic.Add` is required, but no constructor plumbing is needed since the zero value is
  already correct.
- **Reuse `echo_lines` as a stdin-capture harness** — no dedicated capture-mode fake-child helper was
  needed; see Lessons learned below.

## Lessons learned

- The `echo_lines` fake-child mode (`ECHO:<line>` on stdout for each stdin line it receives) doubles as a
  stdin-capture harness for the interrupt round-trip test with zero new helper code: spawn it, wait for
  `READY`, call `Interrupt()`, wait for an `ECHO:` line, strip the prefix, and `json.Unmarshal` the
  remainder to assert `type`/`request.subtype`/`request_id`. The architect spec flagged a dedicated
  `record_stdin` mode as an acceptable fallback if prefix-stripping proved awkward — it didn't, so no new
  mode was added. Worth remembering for any future "capture what got written to the child's stdin" test.
