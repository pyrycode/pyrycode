# Ticket #1040 — remove the dead `AuthenticateFirstFrame` first-frame auth gate

Split from #966. The v1 relay dispatch path that consumed `AuthenticateFirstFrame`
was removed from production in #913 slice 1; the orphaned `dispatch.FirstFrameGate`/
`Dispatcher` machinery it fed was deleted by #1039. `AuthenticateFirstFrame` itself
had zero production callers left — only `internal/relay/auth_test.go` and three
`.go` doc comments referenced it. This ticket deletes it, closing the loop #1039's
documentation pass flagged ("`relay.AuthenticateFirstFrame` itself is untouched …
remains an unreferenced exported function pending its own follow-on").

Not security-sensitive: the removed predicate had zero live callers, so no live
authentication behaviour changes. The live authenticator is the Noise_IK v2
handshake in `v2session.go`/`v2session_handshake.go`, untouched here.

## Implementation

`6fece73` (spec) + `03473bf` (dev), confined to 5 files: −386/+8 lines.

- **`internal/relay/auth.go`** shrank from 162 to 16 lines. Deleted:
  `ErrMalformedHelloFrame`, `AuthOutcome`, `AuthenticateFirstFrame`, and the
  transitively-dead `buildResponse` helper (its only caller was
  `AuthenticateFirstFrame`, both call sites) — staticcheck U1000 would have
  forced its removal even if left behind. Written whole via `Write` (cleaner
  than an `Edit`-delete of 145 scattered lines) rather than block-deleted.
- **Kept in place, unchanged**: `StatusUnauthorized` (4401) and
  `MsgInvalidToken` — still consumed live by `v2session_handshake.go`. The
  spec deliberately kept them in `auth.go` rather than relocating (the ticket
  granted either option) so the `v2session.go:24` comment ("4401
  (StatusUnauthorized) lives in auth.go") stayed accurate instead of becoming
  a fourth stale citation.
- **Import block** collapsed from 8 imports to exactly one:
  `github.com/coder/websocket` (needed for the `StatusUnauthorized` type).
- **`internal/relay/auth_test.go`** (234 lines) deleted whole via `git rm` —
  every test exercised only the removed function. `TestStatusUnauthorized_Value`
  wasn't re-homed; it's subsumed by the live v2 close-code assertions already
  in `v2session_test.go:358/517/4320` and `v2session_debugbundle_test.go:319`.
- **Three stale `.go` comment citations fixed**, all outside `auth.go`/
  `auth_test.go` (grep-confirmed the only three tree-wide):
  `cmd/pyry/relay_guard_test.go:94` re-points the `TypeHello` classification

  updates the `Envelope.Token` field doc to say the field has no live consumer
  (keeping the `SECURITY: … MUST NOT log Token` sentence — `Token` is still
  retained, its removal is separate follow-on scope); `internal/relay/v2session_handshake.go:189`
  drops the `(auth.go's buildResponse)` parenthetical.
- Tree-wide grep for the four removed identifiers returns zero hits (spec's
  belt-and-suspenders check). `make check` green including real-claude e2e.

Code review: PASS, zero deviation from spec (PR #1049).

## Patterns established

- **A ticket can be the pre-planned "own follow-on" another ticket's
  documentation pass flagged.** #1039's `codebase/1039.md` and
  `system-overview.md` both explicitly named `AuthenticateFirstFrame` as
  "remains … pending its own follow-on" — this ticket is that follow-on, and
  closing it means going back and updating the *other* ticket's stale
  cross-references too (`system-overview.md`, `relay-package.md`,
  `protocol-package.md`, `INDEX.md`), not just writing this file.
- **Keep-vs-relocate calls for surviving symbols should optimize for not
  creating a new stale citation.** The spec kept `StatusUnauthorized`/
  `MsgInvalidToken` in `auth.go` specifically because relocating them would
  have turned the accurate `v2session.go:24` comment into a fourth thing to
  fix, on top of the three the ticket already enumerated.

## Lessons learned

- Dead-code removal tickets that reference "a future follow-on" in their own
  history are a signal worth grepping for by name — `AuthenticateFirstFrame`
  showed up as a live cross-reference in four evergreen docs
  (`system-overview.md` ×2, `relay-package.md`, `protocol-package.md`, plus
  the `INDEX.md` one-liner for `v2-session-manager.md`) that had accumulated
  since #249 landed in Phase 3, none of which prior doc passes (#913, #1039,
  #1041) had touched. A `grep -rl AuthenticateFirstFrame docs/` before writing
  is cheap and catches all of them in one pass.
