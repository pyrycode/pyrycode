# Ticket #860 — e2e harness: bind the daemon control socket under a short path (macOS sun_path limit)

`spawnWith` (`internal/e2e/harness.go`) derived the daemon control socket as
`filepath.Join(home, "pyry.sock")`, where `home` is `t.TempDir()`. On macOS
`t.TempDir()` resolves under `/var/folders/<hash>/T/<TestName>/NNN/` and
embeds the sanitised test name, so a sufficiently long test name pushed
`<home>/pyry.sock` past macOS's 104-byte `sockaddr_un.sun_path` limit —
`bind(2)` returned `EINVAL`, the daemon never reached readiness, and the
harness reported a plain "not ready" timeout with nothing pointing at path
length. Four tests already dodged this ad hoc by shortening HOME itself
(`restart_test.go`, `auto_attach.go`, `attach_pty.go`, `fakeclaude_test.go`);
plain `Start(t)` had no such protection. Surfaced live 2026-07-08 while
building #854's interactive real-claude test; #854 was blocked on this
ticket landing.

## Implementation

One production file, one test file, no edit fan-out (S/XS):

- **`internal/e2e/harness.go`** — new package-internal helper
  `shortSocketPath(t *testing.T) string`: `os.MkdirTemp("/tmp", "pyry-sock-*")`
  (→ `/private/tmp`, ~13 bytes — not `os.MkdirTemp("", ...)`, which lands
  under macOS's ~50-byte `/var/folders/...` root), registers
  `t.Cleanup(func() { _ = os.RemoveAll(dir) })`, returns
  `filepath.Join(dir, "pyry.sock")`. `spawnWith` now calls this instead of
  `filepath.Join(home, "pyry.sock")` — the only production line changed.
  HOME is untouched (still `t.TempDir()`); only the socket is decoupled to a
  fresh `~40`-byte path. `spawn`, `StartIn`, `StartInWithEnv`,
  `StartExpectingFailureIn`, `StartRotation`, and `StartRotationWithRelay`
  all funnel through `spawnWith`, so all six became sun_path-safe from this
  one edit — no call site changes.
- **`internal/e2e/socket_path_test.go`** (new file, `//go:build e2e`) —
  regression guard `TestE2E_SocketPath_DeliberatelyLongTestNameStaysUnderMacOSSunPathLimitRegressionGuard860`.
  The long test name **is** the fixture — long enough that the old
  `<t.TempDir()>/pyry.sock` derivation overflows 104 bytes on macOS. Calls
  `Start(t)` (blocks on `waitForReady`, so reaching the next line proves the
  socket bound), then asserts `len(h.SocketPath) <= 104` (the deterministic,
  cross-platform invariant — pre-fix on macOS this is the long nested path,
  post-fix the short `/tmp` path), dials the socket to confirm it's live,
  and checks `filepath.Dir(h.SocketPath) != h.HomeDir` to pin the
  decoupling.

## Patterns established

- **Cleanup ordering relies on `t.Cleanup` LIFO, not explicit sequencing.**
  `shortSocketPath`'s `t.Cleanup(os.RemoveAll(dir))` registers *before*
  `StartIn` registers `h.teardown` (which SIGTERMs/SIGKILLs the daemon and
  waits for exit). LIFO means `teardown` runs first, so the socket dir is
  never removed out from under a live listener — no explicit
  ordering/coordination code needed, just registration order.
- **`/tmp`-rooted `os.MkdirTemp` for socket dirs is now a three-site
  convention**: `internal/control/server_test.go`'s `shortTempDir`,
  `cmd/pyry/rekey_test.go`'s `shortSockTempDir`, and this ticket's
  `shortSocketPath`. All three exist because `os.TempDir()`'s default root
  (`/var/folders/...` on macOS) isn't short enough on its own — `/tmp` (→
  `/private/tmp`) is the established override.
- **Decoupling the socket from HOME, not shortening HOME, is the fix
  when only the socket path is sun_path-tight.** The four pre-existing
  workarounds shorten HOME wholesale (via a short-named `os.MkdirTemp`
  HOME), which also works but is coarser — it constrains every path derived
  from HOME, not just the socket. This ticket deliberately left those four
  workarounds alone (no observed failure forcing a migration); a future
  ticket could unify them onto `shortSocketPath` if one surfaces.

## Cross-harness scope

`internal/e2e/realclaude/` (`//go:build e2e_realclaude`, a separate package
from `internal/e2e`'s `e2e || e2e_install`) was deliberately **not** touched.
That harness runs `pyry agent-run` (one-shot, no control socket) today; it
already duplicates helpers like `ensurePyryBuilt` across the tag boundary
rather than sharing a package (`fixtures.go:323`). When #854 introduces a
live-daemon control socket there, it duplicates the `shortSocketPath` recipe
rather than importing it, consistent with that existing convention.
